# АКОС — домашние задания

Репозиторий содержит индивидуальные задания по дисциплине «Архитектура компьютера и операционные системы».

## Работы

- [ИДЗ 1](idz1/report.md) — последовательная модель читателей и писателей.
- [ИДЗ 2](idz2/README.md) — многопоточная модель читателей и писателей.
- [ИДЗ 3](idz3/README.md) — взаимодействие процессов, разделяемая память, POSIX-семафоры и очереди сообщений.

В каталогах находятся исходный код и отчёты; для ИДЗ 2 и ИДЗ 3 также добавлены инструкции по сборке и запуску.
