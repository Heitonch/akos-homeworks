# ИДЗ №2 — АКОС

Вариант 4. Читатели и писатели: чтение подтверждённых данных.

Многопоточная версия ИДЗ №1. Каждый читатель и писатель выполняется в отдельном потоке `pthread`. Для работы с подтверждённой базой используются мьютекс, семафор писателей и условная переменная для режима ожидания.

## Сборка

Linux / macOS:

    make
    ./idz2

Также можно открыть папку в CLion: конфигурация сборки задаётся в `CMakeLists.txt`.

## Параметры

Программа последовательно запрашивает размер и значения базы, количество читателей и писателей, число операций, диапазон новых значений, число стадий, стратегию читателей и задержки в миллисекундах.

- `0` — `READ_OLD`: во время подготовки чтение предыдущей подтверждённой версии.
- `1` — `WAIT_NEW`: во время подготовки ожидание публикации.
- `0` в поле количества операций — неограниченный режим до `Ctrl+C`.

Для запуска с готовыми параметрами:

    ./idz2 < data/old.txt
    ./idz2 < data/wait.txt
    ./idz2 < data/multi.txt
